# E-Commerce Store - Full Stack Portfolio Project

A clean, responsive e-commerce web application built as a junior developer portfolio project.

## Features

- Modern React frontend with React Router 8
- Shopping cart with persistence
- Product catalog with sample data seeding
- User authentication (Register / Login)
- Paystack payment integration (demo)
- Simple protected admin route
- Responsive design using shadcn/ui + Tailwind

## Tech Stack

**Frontend:**
- React + React Router 8
- TypeScript
- shadcn/ui + Tailwind CSS
- Zustand (state management)
- TanStack Query (data fetching)
- Sonner (toasts)

**Backend:**
- Node.js + Express
- NeDB (embedded database)
- JWT Authentication
- bcryptjs (password hashing)
